# 임베기 정리

## 핵심 개념

### 임베디드 시스템

임베디드 시스템은 특정 기능을 수행하기 위해 장치 내부에 내장된 컴퓨터 시스템이다.

예시:

- 자동차 ECU
- 스마트워치
- 세탁기 제어기
- IoT 센서
- 로봇 제어 장치
- 의료기기

### 임베디드 시스템 특징

| 특징 | 설명 |
|---|---|
| 전용성 | 특정 목적 수행 |
| 실시간성 | 정해진 시간 안에 반응 |
| 제한된 자원 | CPU, 메모리, 전력 제한 |
| 신뢰성 | 오작동 시 위험 가능 |
| 저전력 | 배터리 기반 장치가 많음 |

### MPU와 MCU

| 구분 | MPU | MCU |
|---|---|---|
| 구성 | CPU 중심 | CPU, 메모리, 주변장치 내장 |
| 외부 부품 | 많이 필요 | 적게 필요 |
| 성능 | 높음 | 낮거나 중간 |
| 전력 | 상대적으로 큼 | 낮음 |
| 사용 예 | PC, 고성능 보드 | 센서, 가전, 제어기 |

### 임베디드 하드웨어

| 구성 요소 | 설명 |
|---|---|
| Core | 명령어 실행 |
| Flash | 프로그램 저장, 비휘발성 |
| SRAM | 실행 중 데이터 저장, 휘발성 |
| GPIO | 디지털 입력/출력 |
| Timer | 시간 측정, 주기 이벤트 |
| ADC | 아날로그를 디지털로 변환 |
| DAC | 디지털을 아날로그로 변환 |
| UART | 비동기 직렬 통신 |
| SPI | 고속 동기식 직렬 통신 |
| I2C | 2선식 동기식 직렬 통신 |

### GPIO

GPIO는 범용 디지털 입출력 핀이다.

| 모드 | 설명 |
|---|---|
| Input | 외부 신호 읽기 |
| Output | 신호 출력 |
| Pull-up | 기본값을 High로 유지 |
| Pull-down | 기본값을 Low로 유지 |

### Timer와 PWM

타이머는 시간 측정과 주기적 이벤트 생성에 사용된다.

PWM은 디지털 신호의 듀티비를 조절해 평균 출력을 바꾸는 방식이다.

사용 예:

- LED 밝기 조절
- 모터 속도 제어
- 부저 음 조절

### ADC와 DAC

| 구분 | 설명 | 예시 |
|---|---|---|
| ADC | 아날로그 신호를 디지털 값으로 변환 | 온도 센서 |
| DAC | 디지털 값을 아날로그 신호로 변환 | 오디오 출력 |

ADC 해상도:

- 10비트: 0~1023
- 12비트: 0~4095

### 통신 방식

| 구분 | UART | SPI | I2C |
|---|---|---|---|
| 동기 방식 | 비동기 | 동기 | 동기 |
| 선 개수 | 보통 TX/RX 2개 | MOSI, MISO, SCLK, CS | SDA, SCL 2개 |
| 속도 | 중간 | 빠름 | 중간 |
| 다중 장치 | 제한적 | CS 핀 필요 | 주소 기반 |
| 사용 예 | PC-MCU 시리얼 | Flash, 디스플레이 | 센서, RTC |

### 폴링과 인터럽트

| 구분 | 폴링 | 인터럽트 |
|---|---|---|
| 방식 | CPU가 반복 확인 | 이벤트가 CPU에 알림 |
| CPU 사용 | 많음 | 적음 |
| 구현 | 단순 | 상대적으로 복잡 |
| 반응성 | 확인 주기에 영향 | 빠름 |

### 실시간 시스템

| 종류 | 설명 | 예시 |
|---|---|---|
| Hard Real-Time | 마감 시간 초과가 치명적 | 에어백, 항공 제어 |
| Soft Real-Time | 지연이 품질 저하 | 스트리밍 |
| Firm Real-Time | 늦은 결과는 가치가 거의 없음 | 실시간 주문 처리 |

### RTOS

RTOS는 실시간 처리를 위한 운영체제다.

주요 기능:

- 태스크 관리
- 우선순위 기반 스케줄링
- 세마포어, 뮤텍스, 큐
- 타이머
- 인터럽트 처리 지원

### Watchdog Timer

Watchdog Timer는 시스템이 멈췄을 때 자동으로 재시작시키는 안전장치다.

동작:

1. 프로그램이 주기적으로 watchdog을 갱신한다.
2. 오류로 갱신하지 못하면 타이머가 만료된다.
3. 시스템이 리셋된다.

### 부트 과정

1. 전원 인가
2. Reset vector 실행
3. 부트로더 실행
4. 하드웨어 초기화
5. 펌웨어 또는 OS 로딩
6. main 함수 또는 태스크 실행

## 빈출 정리

### 자주 나오는 비교

| 비교 | 핵심 |
|---|---|
| MCU vs MPU | 통합 제어용 칩 vs CPU 중심 고성능 처리 |
| Flash vs SRAM | 비휘발성 프로그램 저장 vs 휘발성 데이터 저장 |
| 폴링 vs 인터럽트 | 반복 확인 vs 이벤트 알림 |
| UART vs SPI vs I2C | 비동기 2선, 고속 4선, 주소 기반 2선 |
| Hard vs Soft Real-Time | 시간 초과 치명적 vs 품질 저하 |

### 시험에 잘 나오는 문장

- 임베디드 시스템은 특정 목적을 수행하는 내장형 컴퓨터 시스템이다.
- MCU는 CPU, 메모리, 주변장치를 하나의 칩에 포함한다.
- GPIO는 디지털 입력과 출력을 처리한다.
- PWM은 듀티비를 조절해 평균 출력을 제어한다.
- ADC는 아날로그 값을 디지털 값으로 변환한다.
- RTOS는 실시간 태스크 스케줄링을 지원한다.
- Watchdog Timer는 시스템 오류 시 자동 복구를 돕는다.

## 빠른 암기

- MCU = 제어용 통합 칩
- Flash = 프로그램 저장
- SRAM = 실행 중 데이터 저장
- GPIO = 디지털 입출력
- PWM = 듀티비 제어
- UART = TX/RX, SPI = 빠름, I2C = SDA/SCL
- RTOS = 실시간 태스크 관리

## 보강 개념

### Pull-up과 Pull-down

입력 핀이 아무 신호에도 연결되지 않으면 값이 불안정해질 수 있다. 이를 floating 상태라고 한다.

| 구분 | 설명 |
|---|---|
| Pull-up | 입력의 기본값을 High로 유지 |
| Pull-down | 입력의 기본값을 Low로 유지 |
| 사용 예 | 버튼 입력, 스위치 입력 |

### 타이머 활용

| 활용 | 설명 |
|---|---|
| 주기 인터럽트 | 일정 시간마다 ISR 실행 |
| PWM 생성 | 듀티비로 출력 제어 |
| 입력 캡처 | 외부 신호의 시간 측정 |
| 타임아웃 | 일정 시간 내 응답 없으면 오류 처리 |

### 통신 세부 비교

| 구분 | UART | SPI | I2C |
|---|---|---|---|
| 클럭 | 없음 | SCLK 사용 | SCL 사용 |
| 주요 선 | TX, RX | MOSI, MISO, SCLK, CS | SDA, SCL |
| 연결 방식 | 1:1에 가까움 | CS로 장치 선택 | 주소로 장치 선택 |
| 장점 | 단순, 디버깅 편함 | 빠름 | 선이 적고 다중 장치에 좋음 |
| 단점 | 속도/확장 제한 | 선이 많아짐 | 속도가 SPI보다 느림 |

### ISR 작성 주의점

인터럽트 서비스 루틴은 짧고 빠르게 작성해야 한다. 오래 걸리는 처리는 플래그를 세우거나 큐에 넣고, 실제 작업은 메인 루프나 태스크에서 처리하는 방식이 좋다.

### RTOS 동기화 객체

| 객체 | 설명 |
|---|---|
| 뮤텍스 | 공유 자원을 하나의 태스크만 사용 |
| 세마포어 | 이벤트 알림 또는 자원 개수 관리 |
| 큐 | 태스크 사이 데이터 전달 |
| 타이머 | 일정 시간 후 콜백 또는 이벤트 발생 |

## 서술형 답안 틀

### MCU와 MPU

MCU는 CPU, 메모리, GPIO, 타이머, 통신 모듈 같은 주변장치를 하나의 칩에 포함한 제어용 장치다. 반면 MPU는 CPU 중심의 고성능 처리 장치로 외부 메모리와 주변장치가 필요한 경우가 많다. 따라서 MCU는 저전력 제어 장치에, MPU는 복잡한 운영체제나 고성능 처리가 필요한 시스템에 적합하다.

### 폴링과 인터럽트

폴링은 CPU가 장치 상태를 반복적으로 확인하는 방식이고, 인터럽트는 이벤트가 발생했을 때 장치가 CPU에 알려주는 방식이다. 폴링은 구현이 단순하지만 CPU 낭비가 크고, 인터럽트는 효율적이고 반응이 빠르지만 구현과 동기화가 더 복잡하다.

### Watchdog Timer

Watchdog Timer는 시스템이 멈추거나 비정상 상태에 빠졌을 때 자동으로 리셋하기 위한 안전장치다. 정상 동작 중인 프로그램은 주기적으로 watchdog을 갱신해야 하며, 갱신하지 못하면 타이머가 만료되어 시스템이 재시작된다.

## 객관식 필기 시험 전 정리

### 선택지 제거 기준

- ADC가 **디지털을 아날로그로 변환**한다고 하면 틀린 설명이다.
- DAC가 **아날로그를 디지털로 변환**한다고 하면 틀린 설명이다.
- UART가 **클럭선을 사용하는 동기식 통신**이라고 하면 틀린 설명이다.
- I2C가 **장치마다 CS 핀이 필요**하다고 하면 SPI 설명에 가깝다.
- Watchdog Timer가 **성능 향상 장치**라고 나오면 틀린 설명이다.
