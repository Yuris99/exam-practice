# 컴시기 정리

## 핵심 개념

### 컴퓨터 시스템 구성

컴퓨터 시스템은 하드웨어, 소프트웨어, 데이터, 사용자로 구성된다.

| 구성 | 설명 |
|---|---|
| 하드웨어 | CPU, 메모리, 저장장치, 입출력장치 |
| 소프트웨어 | 운영체제, 시스템 프로그램, 응용 프로그램 |
| 데이터 | 프로그램이 처리하는 입력과 출력 |
| 사용자 | 컴퓨터를 사용하는 사람 또는 다른 시스템 |

### CPU

CPU는 명령어를 해석하고 실행하는 장치다.

| 구성 요소 | 역할 |
|---|---|
| 제어장치 | 명령어 해석, 제어 신호 생성 |
| ALU | 산술 연산과 논리 연산 |
| 레지스터 | CPU 내부 고속 임시 저장 공간 |
| 캐시 | CPU와 메모리 사이의 속도 차이 완화 |

명령어 실행 과정:

1. Fetch: 명령어를 메모리에서 가져온다.
2. Decode: 명령어를 해석한다.
3. Execute: 연산 또는 데이터 이동을 수행한다.
4. Write Back: 결과를 저장한다.

### 메모리 계층 구조

| 계층 | 속도 | 용량 | 특징 |
|---|---:|---:|---|
| 레지스터 | 가장 빠름 | 매우 작음 | CPU 내부 |
| 캐시 | 빠름 | 작음 | 자주 쓰는 데이터 저장 |
| RAM | 보통 | 중간 | 실행 중인 프로그램 저장 |
| SSD/HDD | 느림 | 큼 | 영구 저장 |

### 운영체제

운영체제는 하드웨어 자원을 관리하고 사용자 프로그램에 공통 기능을 제공한다.

주요 기능:

- 프로세스 관리
- 메모리 관리
- 파일 시스템 관리
- 입출력 장치 관리
- 보안과 권한 관리

### 프로세스와 스레드

| 구분 | 프로세스 | 스레드 |
|---|---|---|
| 의미 | 실행 중인 프로그램 | 프로세스 내부 실행 흐름 |
| 메모리 | 독립적 | 같은 프로세스 메모리 공유 |
| 생성 비용 | 큼 | 작음 |
| 오류 영향 | 비교적 독립 | 같은 프로세스 전체에 영향 가능 |

프로세스 상태:

- New: 생성 중
- Ready: CPU 할당 대기
- Running: 실행 중
- Waiting/Blocked: 입출력 등 이벤트 대기
- Terminated: 종료

### 스케줄링

| 방식 | 설명 | 특징 |
|---|---|---|
| FCFS | 먼저 온 작업 먼저 실행 | 단순, convoy effect 가능 |
| SJF | 실행 시간이 짧은 작업 우선 | 평균 대기 시간 감소 |
| Round Robin | 정해진 시간만큼 번갈아 실행 | 시분할 시스템에 적합 |
| Priority | 우선순위 높은 작업 먼저 실행 | 기아 현상 가능 |

### 인터럽트

인터럽트는 CPU가 현재 작업을 멈추고 긴급한 일을 처리하도록 하는 신호다.

처리 흐름:

1. 인터럽트 발생
2. 현재 상태 저장
3. 인터럽트 서비스 루틴 실행
4. 상태 복구
5. 원래 작업 재개

### 시스템 콜

사용자 프로그램이 커널 기능을 요청하는 통로다.

예시:

- 파일 열기, 읽기, 쓰기
- 프로세스 생성
- 메모리 할당
- 네트워크 통신

### 가상 메모리

실제 메모리보다 큰 메모리를 쓰는 것처럼 보이게 하는 기법이다.

| 개념 | 설명 |
|---|---|
| 페이지 | 가상 메모리의 고정 크기 단위 |
| 프레임 | 물리 메모리의 고정 크기 단위 |
| 페이지 테이블 | 가상 주소와 물리 주소 매핑 |
| 페이지 폴트 | 필요한 페이지가 RAM에 없을 때 발생 |
| 스와핑 | RAM과 디스크 사이에서 페이지 교체 |

### 네트워크 기초

| 개념 | 설명 |
|---|---|
| IP | 네트워크 장치 주소 |
| TCP | 신뢰성 있는 연결 지향 전송 |
| UDP | 빠른 비연결 전송 |
| DNS | 도메인 이름을 IP 주소로 변환 |
| HTTP/HTTPS | 웹 통신 프로토콜 |

## 빈출 정리

### 자주 나오는 비교

| 비교 | 핵심 |
|---|---|
| 프로세스 vs 스레드 | 독립 메모리 vs 메모리 공유 |
| 캐시 vs 버퍼 | 속도 향상 vs 전송 임시 저장 |
| RAM vs ROM/Flash | 휘발성 vs 비휘발성 |
| TCP vs UDP | 신뢰성 vs 속도 |
| 인터럽트 vs 예외 | 외부/요청 신호 vs 실행 중 특수 상황 |

### 시험에 잘 나오는 문장

- CPU는 Fetch, Decode, Execute 과정을 반복한다.
- 캐시는 시간 지역성과 공간 지역성을 이용한다.
- 운영체제는 자원 관리자 역할을 한다.
- 시스템 콜은 사용자 모드에서 커널 기능을 요청하는 인터페이스다.
- 페이지 폴트는 필요한 페이지가 물리 메모리에 없을 때 발생한다.
- Round Robin은 시간 할당량을 기준으로 CPU를 나눠 쓴다.

## 빠른 암기

- CPU 내부: 제어장치, ALU, 레지스터
- 메모리 속도: 레지스터 > 캐시 > RAM > SSD/HDD
- 프로세스 상태: New, Ready, Running, Waiting, Terminated
- 스케줄링: FCFS, SJF, RR, Priority
- TCP: 정확하게, UDP: 빠르게

| 구분 | 설명 |
|---|---|
| 커널 모드 | 운영체제 핵심 기능 실행, 하드웨어 직접 접근 가능 |
| 사용자 모드 | 일반 프로그램 실행, 제한된 권한 |

### 동기화

공유 자원에 여러 프로세스나 스레드가 동시에 접근하면 데이터가 꼬일 수 있다.

| 개념 | 설명 |
|---|---|
| 경쟁 상태 | 실행 순서에 따라 결과가 달라지는 문제 |
| 임계구역 | 동시에 접근하면 안 되는 코드 영역 |
| 뮤텍스 | 한 번에 하나의 스레드만 접근 |
| 세마포어 | 정해진 개수만큼 접근 허용 |
| 데드락 | 서로 자원을 기다리며 멈춘 상태 |

### 데드락 발생 조건

1. 상호 배제
2. 점유와 대기
3. 비선점
4. 순환 대기

### 스케줄링 평가 기준

| 기준 | 설명 |
|---|---|
| CPU 이용률 | CPU가 쉬지 않고 일하는 비율 |
| 처리량 | 단위 시간당 완료한 작업 수 |
| 대기 시간 | Ready Queue에서 기다린 시간 |
| 응답 시간 | 요청 후 첫 응답까지 걸린 시간 |
| 반환 시간 | 작업 제출부터 완료까지 걸린 시간 |

## 서술형 답안 틀

### 프로세스와 스레드

프로세스는 실행 중인 프로그램으로 독립적인 메모리 공간을 가진다. 스레드는 프로세스 내부의 실행 흐름으로 같은 프로세스의 메모리를 공유한다. 따라서 스레드는 생성과 문맥 교환 비용이 작지만, 하나의 스레드 오류가 전체 프로세스에 영향을 줄 수 있다.

### 캐시 메모리

캐시 메모리는 CPU와 주기억장치 사이의 속도 차이를 줄이기 위한 고속 메모리다. 프로그램의 시간 지역성과 공간 지역성을 이용해 자주 접근하는 데이터를 저장하며, 캐시 히트가 많을수록 평균 메모리 접근 시간이 줄어든다.

### 가상 메모리

가상 메모리는 프로그램마다 독립적인 주소 공간을 제공하고, 필요한 페이지를 물리 메모리에 올려 사용하는 기법이다. 이를 통해 메모리 보호와 효율적인 메모리 사용이 가능하다. 필요한 페이지가 RAM에 없으면 페이지 폴트가 발생한다.

## 객관식 필기 시험 전 정리

### 선택지 제거 기준

- 캐시의 목적이 **용량 증가**라고 나오면 틀린 설명일 가능성이 높다.
- 스레드가 **독립 메모리 공간**을 가진다고 하면 틀린 설명이다.
- UDP가 **신뢰성과 순서 보장**을 제공한다고 하면 틀린 설명이다.
- 가상 메모리가 **물리 RAM을 실제로 늘리는 장치**라고 하면 틀린 설명이다.
- 시스템 콜이 **사용자 프로그램이 커널 기능을 요청하는 통로**라는 말은 맞다.

### 시험 직전 암기 세트

| 항목 | 무조건 기억 |
|---|---|
| CPU | 제어장치, ALU, 레지스터 |
| 명령어 | Fetch → Decode → Execute → Write Back |
| 캐시 | 시간 지역성, 공간 지역성 |
| 프로세스 | 독립 메모리 |
| 스레드 | 메모리 공유 |
| Round Robin | 시간 할당량 |
| 데드락 | 상호 배제, 점유와 대기, 비선점, 순환 대기 |
| TCP | 연결 지향, 신뢰성 |
| UDP | 비연결, 빠름 |
