# 정보보안기사 교재 문제은행 교체 보고서

## 결과

- OCR 원본 1,204페이지는 읽기 전용으로 사용했습니다.
- 자동 추출 후보는 1,846문항입니다. 구조·정답·OCR 신뢰도 검증을 통과한 747문항과 기존 검증 시범 20문항을 중복 없이 등록했습니다. 최종 정보보안기사 문제는 767문항이며 모두 필기 객관식입니다.
- 검수 대기열 1,099문항은 정상 문제로 등록하지 않았습니다. 이 수치는 후보 문항 단위이며, 아래 검수 사유 수는 한 문항에 여러 사유가 붙을 수 있어 합산할 수 없습니다.
- 기존 정적 문제 CSV와 생성 데이터는 등록 전 백업했습니다. 문제 행은 Supabase에 저장되지 않는 구조라 CSV를 갱신하고 `lib/generatedQuestions.ts`를 재생성했습니다. Supabase의 사용자 학습 데이터는 수정하지 않았습니다.

## 데이터 검증 및 표현

- 등록 767문항 모두 보기 4개와 1–4 범위의 정답을 가집니다. 생성기의 중복 키·보기 중복·정답 범위 검증을 통과했습니다.
- 교재에서 해설을 확보하지 못한 22문항은 해설을 만들지 않고 빈 칸으로 두었습니다.
- 등록 데이터 중 참고 지문은 5문항, 코드 필드는 2문항이며 둘 다 시범 20문항에서 가져왔습니다. 별도 이미지가 필요한 문항은 등록 데이터에 없고, 그림·표 검수 대상은 대기열에 남겼습니다.
- 원본 이미지 기준으로 정답 OCR 충돌 1건(PDF 313쪽 37번, OCR 1번 → 이미지 확인 3번)을 정정했습니다.
- 공식 기출 원본 이미지 대조에서 PDF 1151쪽의 `7`/`OIP`를 71번/`OTP`로, PDF 1183쪽의 3번을 68번으로 정정했습니다. 해당 정답·과목·회차 태그도 다시 계산했습니다.
- 2025년 공식 기출에서 문제 본문 시작이 확인되지 않은 번호는 1회 66·88·97번, 2회 12·32번, 4회 53·77·79번입니다. 본문을 추정하지 않고 검수 목록에 남겼습니다.

## 검수 대기열

대기 문항은 로컬 작업본의 `manual-review.csv`와 `manual-review.json`에 원본 PDF 페이지, OCR 텍스트, 보기, 답, 검수 사유와 함께 보존했습니다. 이 대기열과 원본 OCR에서 만든 검수 연락표는 공개 사이트 배포본에 포함하지 않았습니다. 주요 중복 사유는 다음과 같습니다.

- 숫자·코드·경로·특수기호 원본 대조 필요: 645건
- 낮은 OCR 신뢰도: 279건
- 답안 키 미확인: 232건
- 기출 연도 미확인: 206건
- 보기 수가 4개가 아니거나 보기 번호 순서가 불완전한 문항 다수
- 그림·표 확인 필요: 21건

검수 사유는 중복 집계입니다. 특히 숫자·코드·경로가 있는 문항은 원본 이미지에서 확인되지 않으면 등록하지 않았습니다.
